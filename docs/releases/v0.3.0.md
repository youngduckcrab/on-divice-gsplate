# v0.3.0 — M3 온디바이스 학습 v1

폰 GPU에서 3D Gaussian Splatting을 **처음부터 끝까지 학습**하는 첫 버전입니다. 카메라 촬영 대신 [가상 촬영 데이터셋](https://github.com/youngduckcrab/on-divice-gsplate/releases/tag/datasets-v1)으로 학습합니다.

## 변경 사항
- **학습 탭** (앱을 열면 첫 화면)
  - **zip 불러오기**: 데이터셋 zip(`transforms.json` + 이미지 + 마스크 + 깊이)을 앱 안으로 가져옴. 미리보기 영상(mp4)과 평가용 정확한 깊이는 빼고 풀어서 용량을 아낌
  - 설정: **빠름**(360px · 2000회) / **표준**(360px · 4000회) / **고품질**(540px · 7000회), 배경 제거(마스크 사용) 켜기·끄기
  - 진행 화면: 단계 · 경과/남은 시간 · 가우시안 수 · ms/회, 학습 뷰 PSNR 그래프, **검증 뷰 미리보기(왼쪽 학습 결과 / 오른쪽 정답, 눌러서 다른 뷰)**, 패스별 GPU 시간, 발열 상태
  - 끝나면(또는 "중지"를 누르면) 검증 뷰 PSNR을 재고 `.ply`로 저장 → **뷰어에서 보기**, **PLY 내보내기**, **요약 복사**
  - 학습 중에는 화면이 꺼지지 않습니다
- **학습 엔진** (Vulkan compute)
  - 깊이(ARCore 형식) → 점 구름 → 초기 가우시안, 깊이가 없으면 점 구름(`points3d.ply`), 둘 다 없으면 무작위 초기화
  - 타일 래스터라이저 forward/backward, L1 loss, Adam, densify(복제·분할·제거), opacity 리셋, SH 0→3차 단계적 증가
  - Adreno 750에 float atomic이 없어서 **atomic 없이** 그래디언트를 모으는 방식(타일-가우시안 쌍별 합산)으로 구현
  - 모든 파라미터의 그래디언트를 CPU 기준 구현(수치 미분)과 비교하는 테스트를 CI에서 실행
- 데이터셋 `datasets-v1` 갱신: lizard에 `points3d.ply`(SfM 대용 점 구름) 추가 — **lizard zip은 새로 받아 주세요**
- 저장되는 PLY는 일반 3DGS 뷰어(SuperSplat 등)와 같은 축 방향(RDF)입니다

- `gsplat-capture-head.zip` — 머리 스캔(흉상), 마스크 · 깊이 있음 ← **먼저 이것부터**
- `gsplat-capture-body.zip` — 전신 캐릭터, 마스크 · 깊이 있음
- `gsplat-capture-lizard.zip` — 공원의 도마뱀 조각상(배경 포함 전체 장면), 점 구름만 있음

## 테스트 체크리스트
1. 학습 탭 → "zip 불러오기"로 head zip 선택 → 목록에 `gsplat-capture-head` (180장 · 마스크·깊이)가 보이나요? 걸린 시간도 알려 주세요
2. **표준**으로 "학습 시작" → 끝까지 걸린 시간, ms/회, 검증 뷰 PSNR
3. 학습 중 미리보기에서 왼쪽(학습 결과)이 오른쪽(정답)과 점점 닮아 가나요? 스크린샷 1~2장
4. 끝나면 "뷰어에서 보기" → 돌려 보면서 얼굴이 알아볼 만한지, 뒤통수 · 어깨 쪽 상태 (스크린샷)
5. "요약 복사" → 이 대화에 붙여 넣기 (패스별 GPU 시간, 500회 단위 속도 변화, 발열이 들어 있습니다)
6. 여유가 되면: lizard(배경 제거 꺼짐) · body를 **빠름**으로 한 번씩, 그리고 head를 **고품질**로
7. 같은 설정으로 head를 두 번 돌렸을 때 PSNR이 비슷한지 (재현성)

가능하면 **충전기를 빼고**, 폰이 식은 상태에서 시작해 주세요. 학습 중 발열이 심하면(뜨거워서 손으로 잡기 힘들 정도) "중지"를 누르고 그때까지의 요약을 보내 주시면 됩니다.

## 알려진 문제
- 학습 loss는 L1만 씁니다 (D-SSIM은 M4에서 추가 예정) — 경계가 약간 흐릴 수 있습니다
- 앱이 백그라운드로 가면 학습이 멈추거나 느려질 수 있습니다 (학습 중에는 화면을 켜 둔 채로 두세요)
- 학습 속도는 아직 최적화 전입니다 (M5에서 개선). 패스별 GPU 시간을 보고 우선순위를 정합니다
