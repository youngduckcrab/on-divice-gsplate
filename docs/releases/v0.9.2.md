# v0.9.2 — 앱에서 스캔 보기 (사진·누끼·마스크·영상)

## 쓰는 법
학습 탭 데이터셋 줄의 **[메뉴] → 사진·누끼·영상 보기**

## 보기 종류 (위쪽 버튼)
- **사진**: 찍힌 키프레임 그대로(세워서)
- **누끼**: 인물 마스크로 배경을 뺀 모습(빠진 곳은 회색 체크무늬)
  - 학습에 실제로 들어가는 모습입니다
- **마스크**: 사진에서 사람이 아니라고 본 곳을 어둡게(촬영 화면에서 보던 것과 같은 방식)
  - 머리카락·손이 잘렸는지, 배경이 붙어 있는지 보기 좋습니다
- **원래 마스크와 비교**: `-정밀마스크` 데이터셋에서만 나옵니다
  - 왼쪽은 원래 마스크, 오른쪽은 다시 만든 마스크의 누끼
- **촬영 영상**: 촬영 중 녹화된 영상(있는 스캔만)
  - 녹화된 그대로라 옆으로 누워 보일 수 있습니다

## 조작
- 두 손가락으로 확대·이동, 두 번 눌러 원래 크기로
- ◀ ▶ 버튼, 슬라이더, 아래 썸네일 줄로 사진 넘기기
- 검증 사진(8장마다 1장, 학습에 안 씀)은 표시됩니다
- 뒤로 가기나 [닫기]로 목록으로 돌아갑니다

## 설치
v0.9.1 위에 덮어 설치하세요.

## 부탁드리는 것
- 원래 스캔과 `-정밀마스크`를 **원래 마스크와 비교**로 몇 장 넘겨 보고, 머리카락·손·윤곽이 어느 쪽이 정확한지 알려 주세요
- 두 데이터셋의 학습 요약(v0.9.1 부탁)과 같이 보면 다음에 무엇을 고칠지 정할 수 있습니다
