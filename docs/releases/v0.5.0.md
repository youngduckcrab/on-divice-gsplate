# v0.5.0 — 실제 카메라로 사람 스캔 (M2 시작)

지금까지는 가상 촬영 데이터셋으로만 학습했습니다. 이제 **폰 카메라로 사람 주위를 한 바퀴 돌며 찍고, 그 결과로 바로 학습**할 수 있습니다.

## 새 기능: 촬영 탭
- 맨 앞에 **촬영** 탭이 생겼습니다 (처음에 카메라 권한을 묻습니다)
- ARCore로 카메라 위치(포즈)를 추적하고, 1920×1080 이미지와 ARCore 깊이(+신뢰도)를 저장합니다
- **키프레임 자동 선택**: 직전 키프레임보다 충분히 움직였거나(거리의 5%, 최소 3 cm) 5° 이상 돌았을 때, 너무 빠르지 않고(60°/s, 0.8 m/s 이하) 흔들려 흐리지 않을 때(최근 프레임들의 선명도 중앙값과 비교)만 저장합니다. 최대 250장
- **한 바퀴 표시**: 화면 아래 원이 사람 주위 36구간(10°씩)으로 나뉘어, 찍힌 구간이 초록으로 찹니다. 흰색이 지금 위치
- **사람 마스크**: 키프레임마다 ML Kit 인물 분할로 사람 영역을 만들어 함께 저장합니다(배경 제거 학습용)
- 다 찍으면 `scan-날짜-시간` 데이터셋으로 저장되고, **[이 스캔으로 학습]** 을 누르면 학습 탭에서 바로 선택됩니다

## 찍는 방법
1. 사람은 **가만히 서 있고**(팔을 살짝 벌린 자세면 좋음), 촬영자는 **1~1.5 m** 거리에서
2. 처음에 폰을 천천히 좌우로 움직여 추적이 잡히게 합니다(위쪽 안내 문구가 바뀜)
3. 사람을 화면 **가운데 원**에 맞추고 **[시작]**
4. 사람 주위를 **천천히 한 바퀴** 돕니다. 배경이 함께 보이게(추적은 배경의 무늬로 함). 아래 원이 다 차면 **[완료]**
5. 저장이 끝나면 **[요약 복사]** 로 촬영 요약을 보내 주세요. 그다음 **[이 스캔으로 학습]**

## 엔진
- 이미지 크기를 짧은 변 기준으로 맞춥니다: 가로로 저장되는 카메라 이미지(1920×1080)도 빠름·표준에서 960×540, 고품질에서 1280×720으로 학습합니다(세로 데이터셋은 그대로)
- 일부 프레임에만 깊이가 있어도 됩니다(ARCore가 아직 깊이를 못 만든 프레임)

## 설치
v0.4.1 위에 덮어 설치하세요.

## 부탁드리는 것
1. 사람 한 명을 위 방법으로 찍고 **촬영 요약 복사** → 보내 주기
2. **[이 스캔으로 학습]** → 빠름, 배경 제거 켜고 → **학습 요약 복사** → 보내 주기
3. 뷰어에서 결과가 어떻게 보이는지(사람 모양이 맞는지, 이중으로 겹쳐 보이지 않는지)
4. 촬영 중 불편했던 점(안내 문구, 원 표시, 끊김 등)
