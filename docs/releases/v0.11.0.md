# v0.11.0 — 뷰어 배경 고르기 (가상 공간·내 사진·360° 사진)

뷰어에서 모델 뒤의 배경을 바꿀 수 있습니다. 고른 배경은 기억해 두었다가 다음에도 씁니다.

## 쓰는 법
뷰어 아래 줄의 **[배경]** → 위쪽 버튼에서 고르기

| 배경 | 모습 |
|---|---|
| 기본 | 지금까지의 어두운 회색 |
| 흰 스튜디오 | 끝없는 흰 바닥이 벽으로 이어지는 사진 스튜디오 |
| 어두운 무대 | 어두운 방, 발밑에 조명이 동그랗게 비침 |
| 하늘·잔디 | 해가 떠 있는 하늘과 잔디밭 |
| 체크 바닥 | 지평선까지 이어지는 체크무늬 바닥 |
| 노을 | 저녁 하늘과 해, 바닥에 비친 노을빛 |
| 밤하늘 | 별이 뜬 하늘, 발밑에 푸른 빛 |
| 내 사진 | 폰의 사진을 고름 (아래 참고) |

- 그린 배경들은 **진짜 3D 공간**입니다: 모델을 돌리면 배경도 같이 돌고, 위에서 보면 바닥이 보입니다
- 바닥은 모델의 가장 낮은 곳(발밑)에 깔리고, 발밑에 **부드러운 그림자**가 생깁니다
- 모델을 바닥 아래에서 올려다보면 바닥 없이 하늘만 보입니다

## 내 사진
- **가로:세로가 2:1인 사진(360° 파노라마)** → 모델을 **빙 둘러쌉니다**. 돌리면 주변 풍경이 같이 돕니다. 발밑에 옅은 그림자가 생깁니다
  - 갤럭시 카메라의 파노라마·360 카메라 사진 등
- **그 밖의 사진** → 화면을 꽉 채워 **뒤에 깔립니다**. 모델을 돌려도 사진은 그대로입니다
- 사진은 화면 크기에 맞게 줄여서 씁니다 (파노라마 가로 4096, 일반 사진 긴 쪽 2048)

## 참고
- 배경은 뷰어에서 보는 모습만 바꿉니다. 모델 파일(PLY)에는 들어가지 않습니다
- 얼굴 가리기와 같이 쓸 수 있습니다

## PC 확인
- 같은 셰이더를 PC 렌더러(`gs_render --backdrop`)로 그려 아홉 가지 모두 확인
- 폰 화면 회전(0·90·180·270°)에서 배경과 모델이 같은 방향으로 그려지는지, 스튜디오 바닥의 그림자, 360° 사진의 위아래 방향을 엔진 테스트로 확인
