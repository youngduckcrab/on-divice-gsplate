# v0.3.3 — 엔진 자가 검사

"설정을 바꿔도 품질이 비슷하고, 미리보기가 학습 중에 거의 안 바뀐다"는 피드백에 대한 진단 버전입니다.
제 쪽(PC의 소프트웨어 GPU)에서는 같은 엔진으로 head를 학습하면 검증 PSNR이 24 → 40 dB까지 오르며 선명해지는데, 폰에서는 그렇지 않다면 **폰 GPU에서 계산이 다르게 되고 있을** 가능성이 큽니다. 이를 폰에서 직접 확인하는 기능을 넣었습니다.

## 변경 사항
- **학습 탭 → "엔진 자가 검사"** (1분 안쪽)
  - 폰 GPU로 계산한 그래디언트(학습 방향)를 CPU로 정밀하게 계산한 기준값과 파라미터마다 비교합니다. 빠른 합산(subgroup)과 대체 합산(shared) 두 방식, 마스크 유무 모두
  - 정답을 아는 작은 장면을 600회 학습해서 PSNR이 오르는지 확인합니다
  - 결과는 화면과 "요약 복사"에 들어갑니다
- "요약 복사"에 **학습 뷰 PSNR 추이**(학습을 10구간으로 나눈 평균)를 추가 — 학습이 실제로 진행됐는지 숫자로 보입니다
- GPU → CPU로 결과를 읽을 때 필요한 메모리 동기화(host barrier)를 추가 (Vulkan 규칙상 필요, 일부 모바일 드라이버에서 값이 늦게 보일 수 있음)

## 설치
v0.3.2 위에 덮어 설치하세요.

## 부탁드리는 것
1. 학습 탭 맨 아래 **"자가 검사 실행"** → 끝나면 **"요약 복사"** 해서 보내 주세요 (가장 중요)
2. head를 **배경 제거 켠 상태로 표준** 학습 → 끝나면 "요약 복사" + 미리보기 스크린샷
