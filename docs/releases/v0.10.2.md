# v0.10.2 — 앱을 다시 켜도 모델과 얼굴 가리기가 남도록, "내 모델" 목록

앱을 껐다 켜면 [얼굴 가리기] 버튼이 사라지던 문제를 고쳤습니다. 원인은 두 가지였습니다.
- **앱만 닫히고 앱 프로세스는 살아 있던 경우**: 모델은 그대로 보이는데, 화면 쪽이 "파일에서 연 모델"이라는 걸 잊어서 버튼이 숨었습니다
  - → 이제 화면을 다시 만들 때 보이던 모델, 얼굴 위치, 고른 방식·크기·위아래를 그대로 이어받습니다
- **앱이 완전히 꺼진 경우**: 뷰어가 합성 샘플로 시작했고, 학습한 모델은 앱 안쪽 저장소에 있어서 [파일 열기]로는 찾을 수 없었습니다
  - → 이제 **마지막으로 연 모델을 자동으로 다시 엽니다** ([파일 열기]로 연 파일도 권한을 유지해 다시 엽니다)

## 새로 생긴 것
- 뷰어 **[내 모델]**: 학습한 모델이 모두 나옵니다 (최신순, 크기·날짜). 누르면 열리고, [삭제]로 지울 수 있습니다 (확인 후)
- 얼굴 가리기 패널의 저장 버튼이 둘로 나뉩니다
  - **[내 모델에 저장]**: 가린 모델을 앱 안에 저장 → [내 모델]에서 언제든 다시 열기 (`원래이름-모자이크.ply`)
  - **[파일로 내보내기]**: 기존 [PLY로 저장]과 같이 원하는 폴더에 저장

## 참고
- 가린 모습은 저장해야 남습니다. 저장하지 않고 앱이 완전히 꺼지면 다시 켰을 때 원래 모델이 열리고, [얼굴 가리기]를 다시 누르면 됩니다 (몇 초)
