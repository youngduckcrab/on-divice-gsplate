# v0.4.1 — D-SSIM 가중치를 학습 후반으로 갈수록 키움

v0.4.0 결과 (body, 배경 제거, 빠름 540×960): 65.6 s, **검증 PSNR 42.10 dB · SSIM 0.9945**, "얼굴도 선명해지고 좋네". 발열 헤드룸 줄로 학습 중간에 느려지는 원인이 발열 제한(MODERATE에서 1회 20 → 46 ms)임을 확인.

## 변경 사항
- **손실의 D-SSIM 가중치 λ를 0.2 → 1.0으로 선형 증가** (사용자 제안)
  - 손실 = (1 − λ) × L1 + λ × (1 − SSIM). 처음에는 L1 비중이 커서 색과 모양을 먼저 맞추고, 끝으로 갈수록 SSIM(윤곽·질감)에 집중합니다. 마지막 단계에서는 SSIM만 씁니다
  - 요약의 설정 줄에 `손실 L1+D-SSIM (λ 0.2 → 1.0)`이 나옵니다

## PC(lavapipe) 비교 (body 360×640, 600회, 손실만 바꿈, 검증 23장)

| 손실 | 검증 PSNR | 검증 SSIM |
|---|---|---|
| L1만 | 34.96 dB | 0.9756 |
| λ 0.2 고정 (v0.4.0) | 36.14 dB | 0.9810 |
| λ 0.2 → 0.6 | 36.82 dB | 0.9852 |
| **λ 0.2 → 1.0 (v0.4.1)** | **37.22 dB** | **0.9871** |

- L1을 끝에 빼면 색이 틀어질 수 있다고 예상했지만, 이 비교에서는 PSNR(색 정확도)까지 올라갔습니다. 앞쪽 절반은 L1 비중이 커서 색이 먼저 맞춰지고, SSIM만 쓰는 구간이 끝부분뿐이라 색이 틀어질 시간이 없는 것으로 봅니다
- 수렴 테스트(작은 장면 600회): 37.14 → 37.41 dB
- 전체 테스트 통과, Vulkan 검증 레이어 오류 0
