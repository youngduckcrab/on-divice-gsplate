# v0.7.2 — zip 불러오기 상태 표시, 다른 앱에서 바로 열기

## zip 불러오기가 무엇을 하는지 바로 보입니다
- [zip 불러오기] 버튼 바로 아래에 상태가 나옵니다
  - 파일을 고르지 않고 돌아오면: "파일이 선택되지 않았어요…"
  - 불러오는 중: "압축 푸는 중… 120 MB / 350 MB" (영상처럼 학습에 안 쓰는 큰 파일을 건너뛰는 동안에도 숫자가 움직입니다)
  - 끝나면: "불러옴: scan-… (170장)" 또는 "불러오기 실패: 이유"
  - 학습 중에 누르면: "학습 중에는 불러올 수 없어요…"
- 내보내기 진행률도 같은 자리에 나옵니다

## 다른 앱에서 zip을 바로 열 수 있습니다
- 카카오톡, 내 파일, 구글 드라이브 등에서 데이터셋 zip을 누르고 **"다음으로 열기" / "공유" → GSplat Lab**을 고르면, 학습 탭으로 넘어가 바로 불러옵니다
