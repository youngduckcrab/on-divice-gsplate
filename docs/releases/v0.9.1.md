# v0.9.1 — 인물 마스크 다시 만들기 (정밀)

v0.9.0의 PC 시뮬레이션에서 **사진마다 흔들리는 인물 마스크 경계**가 실제 스캔 숫자(검증 31 dB, 머리 24 dB)를 거의 그대로 재현했습니다. 그래서 마스크 자체를 더 정확하게 만드는 방법을 넣었습니다.

## 왜 마스크가 거친가
- 촬영 중 인물 분할(ML Kit)은 사진 전체를 한 번에 계산합니다
- 이 모델은 내부에서 약 256픽셀로 줄여서 보기 때문에, 전신 사진에서 **머리는 수십 픽셀**밖에 안 됩니다
- 그래서 머리카락·손·윤곽이 뭉개지고, 사진마다 조금씩 다르게 나옵니다

## 고친 방법: 잘라서 다시 분할
- 사람 주위를 잘라서 한 번, **머리·어깨 부분을 따로 잘라서 한 번** 더 분할합니다
- 같은 모델이 머리를 몇 배 크게 보게 되어 경계가 훨씬 정확해집니다
- 잘라 낸 부분의 경계는 원래 마스크와 부드럽게 섞어 사각형 자국이 안 생기게 했습니다

## 쓰는 법 (기존 스캔에 바로)
- 학습 탭 데이터셋 줄의 버튼 이름이 **[메뉴]**로 바뀌었습니다(내보내기 항목은 그대로 있음)
- [메뉴] → **마스크 다시 만들기 (정밀, 새 데이터셋으로 복사)**
- `원래이름-정밀마스크`라는 새 데이터셋이 생기고 자동으로 선택됩니다(원래 스캔은 그대로)
- 140장 기준 1분 안쪽 걸릴 것으로 예상합니다(진행률이 데이터셋 목록 아래에 나옴)

## PC 확인 (같은 계열 모델, 가상 전신 촬영, 정답 마스크와 비교)
| | 한 번에 분할 | **잘라서 다시** |
|---|---|---|
| 겹침(IoU) | 0.76 | **0.85** |
| 머리 겹침 | 0.74 | **0.89** |
| 틀린 픽셀 | 22,362 | **13,264** (−41%) |

- 실제 사람 사진과 ML Kit에서는 결과가 다를 수 있어서, 같은 스캔으로 직접 비교해 봐야 합니다

## 설치
v0.9.0 위에 덮어 설치하세요.

## 부탁드리는 것
1. `scan-20261031-183117`을 [메뉴] → **마스크 다시 만들기**
2. 원래 스캔과 새 `-정밀마스크` 스캔을 **같은 설정**(빠름, 보정 모두 켬)으로 각각 학습 → 두 요약 모두 "요약 복사"
   - 검증·머리 PSNR, `진단 ·` 줄(특히 마스크 경계 비율)
3. 뷰어에서 두 결과의 머리카락·손·윤곽이 어떻게 다른지
4. 좋아지면 촬영할 때부터 이 방식으로 마스크를 만들도록 바꾸겠습니다
