# v0.3.7 — 폰에서 가장 빠른 역전파를 직접 재서 선택

v0.3.6 결과 (body, 배경 제거, 빠름):
- 학습 후반: 1회 77 → 39 ms (가려진 가우시안 건너뛰기 효과)
- 학습 초반: 1회 30 → 98 ms (가우시안 2개 묶음 처리가 Adreno에서는 오히려 느림 — 공유 메모리를 두 배로 써서 GPU가 동시에 돌릴 수 있는 작업 수가 줄어든 것으로 보임)
- 전체 105 s → 132 s, 결과(PSNR 40.0 dB)는 같음

## 변경 사항
- **역전파 방식을 폰에서 직접 재서 고름**: 학습 전 검증 단계에서 그래디언트가 맞는 방식들을 각각 작은 부하로 시간을 재고 **가장 빠른 것**을 씁니다 (앱 실행 후 처음 한 번, 2초 안쪽). 후보: 건너뛰기만 하는 serial_cut, 건너뛰기 + 2개 묶음 serial_cut2 (+ subgroup 방식이 컴파일되는 기기라면 그것도)
- 예상: serial_cut이 뽑히면 초반은 v0.3.5 수준(30 ms), 후반은 v0.3.6 수준(40 ms 이하) → "빠름" 전체 약 70초
- "요약 복사"의 GPU 검증 줄에 방식별 측정 시간이 나옵니다

## 설치
v0.3.6 위에 덮어 설치하세요.

## 부탁드리는 것
1. body **배경 제거 켜고 빠름** → "요약 복사" (GPU 검증 줄에 방식별 ms가 나옵니다)
2. **자가 검사 실행** → "요약 복사" (지난번에 빠졌던 subgroup 조합 결과가 필요합니다)
