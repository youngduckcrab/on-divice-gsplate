# v0.12.0 — 실제 사진 배경(실내 6·야외 8)과 배경에 맞춰 모델 조명 바꾸기

v0.11.0의 그린 배경을 **실제 360° 사진**으로 바꿨습니다. 그리고 모델이 배경과 따로 노는 문제(예: 노을 배경인데 모델은 낮 조명 그대로)를 고치려고, **배경의 빛으로 모델을 다시 칠합니다**.

## 배경 (뷰어 → [배경])
- **실내**: 카페 · 밝은 스튜디오 · 빈티지 방 · 궁전 홀 · 박물관 · 크리스마스
- **야외**: 노을 바다 · 해돋이 들판 · 정원 · 베네치아 골목 · 런던 시장 · 밤 광장 · 숲길 · 시골길
- **기타**: 기본(어두운 회색) · 흰 스튜디오 · 내 사진
- 모두 Poly Haven의 360° HDR 사진(CC0)입니다. 출처는 `docs/backdrops.md`
- 그림·노을·체크 바닥 같은 v0.11.0의 그린 배경은 뺐습니다 (흰 스튜디오만 남김)

## 사진 속에 서 있게
- **발밑에 사진의 바닥**: 사진을 찍은 높이(약 1.5~1.7 m)와 주변까지의 거리를 정해 두고, 모델 발밑에는 사진의 바닥이 오도록 투영합니다. 모델을 돌려도 바닥 위에 서 있습니다
- **렌즈처럼 흐림**: 모델과 같은 거리(발밑 바닥)는 또렷하고, 멀어질수록 흐려집니다 (인물 사진처럼)
- **그림자**: 발밑에 옅은 그림자, 그리고 해·창문 같은 주된 빛의 반대쪽으로 그림자가 늘어집니다. 해가 강한 곳일수록 진합니다

## 배경에 맞춘 조명 (조명 슬라이더, 기본 100%)
- 배경 사진(HDR)에서 **어느 방향에서 어떤 색의 빛이 얼마나 오는지** 미리 계산해 두고, 모델의 각 점을 그 빛으로 다시 칠합니다
  - 노을: 분홍·주황빛 / 밤: 어둡게 / 해돋이: 역광으로 머리·어깨 테두리가 빛남 / 실내: 조명 색과 방향
- 휴대폰 카메라가 인물에 노출을 맞추듯, 화면을 보는 쪽이 너무 어두워지지 않게 일부 보정합니다
- **조명** 슬라이더: 0%면 찍은 그대로, 100%면 배경 빛을 그대로 입힙니다
- 내 사진도 사진의 색·밝기·방향으로 조명을 계산합니다 (일반 사진은 그 사진이 주변을 감싼다고 보고 대략)

## 참고
- 배경과 조명은 보는 화면에만 적용됩니다. 저장하는 PLY 파일의 색은 바뀌지 않습니다
- 앱 크기가 약 11 MB 커졌습니다 (배경 사진)
- 배경 사진은 대부분 2048×1024라 폰 화면에서 약간 흐립니다. 일부러 흐림 효과를 넣어 인물 사진처럼 보이게 했습니다

## PC 확인
- 같은 셰이더를 PC 렌더러(`gs_render --env`)로 그려 14장 모두 확인
- 엔진 테스트: 회색 점이 따뜻한 빛에서 붉어지고 어두운 곳에서 어두워지는지, 조명 0%면 그대로인지, 화면 회전 4방향에서 배경 방향이 맞는지
