# v0.7.1 — 데이터셋 내보내기, 촬영 영상 저장

## 데이터셋 내보내기 (zip)
- 학습 탭 데이터셋 목록의 각 줄에 **[내보내기]** 버튼이 생겼습니다
- 누르면 저장 위치를 고르는 창이 뜨고(다운로드 폴더, 구글 드라이브 등), zip 하나로 저장됩니다
- zip 안에 들어가는 것:

| 폴더/파일 | 내용 |
|---|---|
| `recording.mp4` | 촬영 영상 (v0.7.1부터 찍은 스캔만) |
| `images/` | 키프레임 사진 (1280×720, 카메라 센서 방향이라 옆으로 누워 있음) |
| `masks/` | 사람 마스크 (흰색 = 사람) |
| `cutout/` | **누끼 이미지**: 키프레임마다 배경을 투명하게 뺀 사진, 바로 세운 방향 (WebP) |
| `depth/`, `confidence/` | ARCore 깊이와 신뢰도 |
| `transforms.json` | 사진마다 카메라 위치·방향, 카메라 내부 값 |

- 이 zip은 학습 탭의 **[zip 불러오기]**로 다른 폰에 그대로 넣을 수 있습니다(영상과 누끼 이미지는 학습에 안 써서 불러올 때 뺍니다)
- 크기는 170장 기준 키프레임만 수십 MB, 영상까지 넣으면 더 큽니다. 내보내는 데 수십 초 걸릴 수 있고, 진행률이 상태 줄에 나옵니다

## 촬영 영상 저장
- [시작]부터 [완료]까지의 카메라 영상이 스캔 안에 `recording.mp4`로 저장됩니다
- 영상과 함께 ARCore 위치 추적 데이터도 같은 파일에 들어갑니다(나중에 앱에서 다시 처리할 수 있게)
- 기기가 녹화를 지원하지 않으면 촬영은 그대로 되고, 촬영 요약의 `녹화 영상:` 줄에 이유가 나옵니다

## 주의
- 데이터셋과 영상에는 찍힌 사람의 얼굴이 그대로 들어 있습니다. 다른 사람에게 보낼 때는 찍힌 분의 동의를 받아 주세요
