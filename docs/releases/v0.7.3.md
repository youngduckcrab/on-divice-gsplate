# v0.7.3 — 끊긴 zip도 불러오기, 영상은 따로 내보내기

"불러오기 실패: Unexpected end of ZLIB input stream"은 **zip 파일이 중간에서 끊겨 있다**는 뜻이었습니다.
내보내기가 끝나기 전에 파일을 보냈거나, 전송 중에 잘린 경우입니다. 파일은 내보내기를 시작하자마자 폴더에 생기고, 그 뒤로 계속 채워집니다.

## 고친 것
- **끊긴 zip도 받은 부분까지는 불러옵니다**
  - "불러옴: … zip이 중간에서 끊겨 있어서 받은 부분까지만 (사진 n/170장)"
  - 사진이 절반 이상 있으면 그대로 학습할 수 있습니다
- **내보낼 때 카메라 위치 파일(transforms.json)을 맨 앞에, 영상을 맨 뒤에 넣습니다**
  - 그래서 끊겨도 앞부분은 쓸 수 있습니다
  - 이전 버전(v0.7.1~0.7.2)으로 만든 zip은 이 파일이 영상 뒤에 있어서, 끊기면 불러올 수 없습니다. 새로 내보내 주세요
- **[내보내기]를 누르면 세 가지 중에서 고릅니다**
  - **데이터셋 zip** (사진·누끼·깊이·위치, 영상 제외): 가볍고, 학습과 PC 분석에는 이것으로 충분합니다
  - **데이터셋 zip + 촬영 영상**: 큽니다
  - **촬영 영상만 (mp4)**: 갤러리나 동영상 앱에서 바로 볼 수 있습니다
- 내보내는 동안 "끝나기 전에 보내면 파일이 잘려요"가 표시되고, 끝나면 "이제 보내도 돼요"가 나옵니다
- 이미 있는 파일에 덮어쓸 때 예전 내용이 뒤에 남지 않게 했습니다
