# v0.3.8 — subgroup 역전파 재도전

v0.3.7 결과 (body, 배경 제거, 빠름): **105 s → 75 s**. 폰에서 잰 결과 serial_cut(18.5 ms)이 serial_cut2(24.6 ms)보다 빨라 자동으로 선택됐고, 역전파가 1회 47.8 → 21.9 ms로 줄었습니다. 품질은 그대로(40.1 dB).

## 변경 사항
- **subgroup 역전파 두 가지 추가** (subgroup_lane4, subgroup_lane1)
  - 폰에서 **하나씩은 컴파일된** subgroup 기능(기본 내장값, 실수 덧셈)만 씁니다. 컴파일이 거부된 셰이더에만 들어 있던 기능(subgroup 번호·개수, elect, 벡터 덧셈)은 쓰지 않습니다
  - 픽셀 256개의 합을 공유 메모리 대신 subgroup 덧셈으로 구해서, 성공하면 지금 역전파보다 크게 빨라질 수 있습니다
  - 학습 전 검증에서 컴파일되고, 그래디언트가 맞고, 더 빠를 때만 쓰입니다. 아니면 지금처럼 serial_cut으로 학습합니다
- "요약 복사"의 GPU 검증 줄에 새 방식들의 결과(사용 불가 / 틀림 / 정상 + ms)가 나옵니다

## 설치
v0.3.7 위에 덮어 설치하세요.
