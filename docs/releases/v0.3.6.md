# v0.3.6 — 역전파 속도 개선 (1차) + 시간 측정

v0.3.5에서 학습이 처음으로 맞게 동작했지만, 역전파가 GPU 시간의 70~80%를 차지했습니다 (body 배경 제거 시 1회 48 ms, 배경 포함 시 194 ms).

## 변경 사항
- **새 역전파 "serial_cut2"**
  - 타일마다 "마지막으로 화면에 기여한 가우시안"까지만 계산합니다. 그보다 뒤에서 이미 가려진 가우시안은 건너뜁니다 (순전파가 타일별로 그 위치를 기록)
  - 가우시안 2개를 한 번에 처리해 스레드 동기화(barrier) 횟수를 절반으로 줄였습니다
  - PC에서는 역전파가 25~35% 빨라졌고, 결과는 기존 방식과 비트 단위로 같습니다. 폰에서는 동기화 비용이 더 커서 효과가 더 클 수 있습니다
  - 학습 전 폰 GPU 검증 순서: subgroup → subgroup 스칼라 → **serial_cut2** → serial_cut → serial(v0.3.5에서 검증된 그대로 보존) → shared. 그래디언트가 맞는 첫 번째 방식을 씁니다
- **"요약 복사"에 제출별 시간 추가**: GPU가 실제로 일한 시간과 기다린 시간(벽시계)을 나눠서 보여 줍니다. 1회 76 ms 중 GPU 밖에서 쓰이는 약 30 ms가 어디서 나오는지 찾는 데 씁니다
- **자가 검사: subgroup 조합 검사 추가** (vec4 덧셈, 덧셈+id, 덧셈+elect, 덧셈+개수, 덧셈+공유 메모리, 덧셈+반복문, 전체 조합). 기능 하나씩은 되는데 조합하면 안 되는 원인을 찾아 가장 빠른 방식을 살리기 위한 정보입니다

## 설치
v0.3.5 위에 덮어 설치하세요.

## 부탁드리는 것
1. body를 **배경 제거 켜고 빠름**으로 학습 → "요약 복사" (v0.3.5 결과: 105 s, 역전파 47.8 ms와 비교)
2. "자가 검사 실행" → "요약 복사" (subgroup 조합 결과)

## 배경 제거를 끄면 느리고 배경이 잘 안 나오는 이유
- 배경까지 학습하면 방 전체(벽, 바닥, 그림)의 깊이 점이 들어와 가우시안이 4만 → 10만 개, 타일-가우시안 쌍이 14만 → 66만 개로 늘어납니다. 계산량이 4~5배라 1회 75 → 190~250 ms가 됩니다
- 깊이(ARCore 방식)는 해상도가 낮고 멀수록 노이즈가 커서, 2~4 m 떨어진 벽은 시작점이 부정확합니다. 2000회로는 벽의 무늬까지 맞추기 부족하고, 깊이에 구멍이 난 곳은 가우시안이 아예 없습니다
- 사람 스캔이 목표이므로 **배경 제거를 켠 상태가 기본이자 권장**입니다
