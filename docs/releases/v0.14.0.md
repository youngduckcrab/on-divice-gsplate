# v0.14.0 — 직접 만든 3D 장소: CG 거실, 사진 스튜디오

남이 촬영해 공개한 장면만으로는 장소가 3곳뿐이라, **장소를 직접 지었습니다.** Blender에서 방을 만들고, 빛(해·하늘·조명과 벽에서 튕긴 빛)을 계산해 표면에 구운 뒤, 표면을 2~3 cm 간격의 가우시안으로 바꿨습니다. 그래서 다른 장소처럼 모델과 함께 3D로 그려집니다: 시점을 돌리면 가구가 진짜로 앞뒤로 움직이고, 앞의 가구는 모델을 가립니다.

## 새 장소
뷰어 → **[장소]** → 실내
- **CG 거실**: 큰 창으로 햇살이 드는 거실. 벨벳 소파, 의자 둘, 러그, 커피 테이블과 꽃, 책장, 사이드보드와 그림, 스탠드와 펜던트 조명, 화분. 창밖에 잔디와 나무
  - 자리 두 곳: **소파 앞**, **창가**
- **사진 스튜디오**: 종이 배경지 위에 서는 촬영 스튜디오. 옥타박스(주광), 스트립(역광), 배경 조명, 반사판(V-플랫), 삼각대 카메라, 분장 거울, 옷걸이
  - 모델에 스튜디오 조명이 그대로 입혀집니다 (한쪽은 밝고 반대쪽은 그늘)

## 어떻게 만들었나
- `tools/environments/blender/`: 방과 가구, 재질, 조명을 모두 코드로 만드는 스크립트 (`living_room.py`, `studio.py`, 공통 `place_kit.py`)
- Cycles로 빛을 굽고(bake), 빛과 표면 색을 따로 구운 뒤 빛만 부드럽게 해 잡음을 없앴습니다
- 일부 가구는 Khronos glTF 샘플 에셋(Wayfair 등, CC BY 4.0 / CC0)을 썼습니다. 출처는 `docs/environments.md`와 앱의 장소 화면에 있습니다
- `gs_place`: PLY/SPZ 파일을 앱의 장소 파일(.gsenv)로 바꾸는 도구
