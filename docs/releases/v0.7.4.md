# v0.7.4 — 내보내기를 끝까지 다 만든 뒤에만 보이게, [바로 보내기]

앱으로는 불러와지는데 파일 관리자에서 "파일이 없습니다"로 나오던 zip은, **끝부분(누끼 이미지)에서 잘린 파일**이었습니다.
- zip은 안에 든 파일 목록을 **맨 끝**에 적습니다. 파일 관리자는 그 목록을 읽어서 보여 주기 때문에, 끝이 잘리면 아무것도 안 보입니다
- 앱은 zip을 **앞에서부터** 읽어서, 학습에 필요한 부분(사진·마스크·깊이·위치)이 있으면 불러옵니다
- 이전 버전은 저장할 파일을 바로 만들고 그 안을 채워 나갔습니다. 누끼 이미지를 만드는 마지막 단계가 가장 오래 걸려서, 그 사이에 보내면 끝이 잘렸습니다

## 바뀐 것
- **zip을 앱 안에서 다 만든 뒤에 저장 위치로 복사합니다**
  - 고른 폴더에는 다 만들어진 파일만 생기고, 만드는 도중의 파일은 보이지 않습니다
- **[바로 보내기]가 생겼습니다**
  - [내보내기] → **데이터셋 zip 바로 보내기**를 고르면, 다 만든 뒤에 공유 창이 열립니다(카카오톡, Quick Share, 드라이브 등)
  - 덜 된 파일을 보낼 일이 없어서 가장 안전합니다
- **촬영 영상**도 바로 보내기와 저장 중에서 고를 수 있습니다
- 누끼 이미지를 4개씩 동시에 만들어 내보내기가 빨라졌습니다

## [내보내기] 메뉴
- 데이터셋 zip 바로 보내기 (추천)
- 데이터셋 zip 저장
- 촬영 영상 바로 보내기 / 촬영 영상 저장 (영상이 있는 스캔만)
- 데이터셋 zip + 촬영 영상 저장 (큼)
