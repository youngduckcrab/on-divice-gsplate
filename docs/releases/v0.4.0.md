# v0.4.0 — 품질 1단계: D-SSIM 손실, 해상도 상향

v0.3.11 결과 (body, 배경 제거, 고품질 540×960 · 7000회): **158 s** (v0.3.6 465 s), 검증 42.96 dB. 시작 GPU 검증 8.2 s → **0.8 s**. 다만 학습 중간에 1회 시간이 13 → 36 ms로 올랐다가 끝에 13 ms로 돌아왔습니다(모든 단계가 같이 느려짐 → GPU 클럭 제한으로 보임).

## 변경 사항
1. **D-SSIM 손실**
   - 지금까지 손실은 픽셀별 오차(L1)만 봤습니다. 이제 3D Gaussian Splatting 기본값처럼 **0.8 × L1 + 0.2 × (1 − SSIM)** 으로 학습합니다
   - SSIM은 11×11 창 안의 밝기·대비·구조가 얼마나 같은지를 보는 지표라, 윤곽과 질감처럼 L1이 뭉개기 쉬운 부분을 살립니다
   - GPU에서 SSIM과 그 그래디언트를 계산합니다(타일별 공유 메모리, 가로·세로로 나눈 가우시안 창)
   - 학습 전 GPU 검증이 SSIM까지 포함해 CPU 기준과 그래디언트를 비교합니다
   - 요약에 **학습 뷰 SSIM, 검증 SSIM**(1에 가까울수록 좋음)과 GPU 단계별 `SSIM` 시간이 나옵니다
2. **해상도 상향** (데이터셋 원본 720×1280)
   - 빠름 2000회 · 표준 4000회: 360×640 → **540×960**
   - 고품질 7000회: 540×960 → **720×1280**
   - v0.3.11에서 540×960의 1회 시간이 360×640과 거의 같아서(폰이 식은 상태 12 → 13~15 ms) 시간 증가가 작을 것으로 봅니다. 고품질은 픽셀이 1.8배라 더 걸립니다
3. **발열 추이**
   - 500회마다 발열 헤드룸을 기록해 요약에 `발열 헤드룸` 줄로 보여 줍니다. 1에 가까울수록 GPU가 클럭을 낮춥니다. 학습 중간에 느려지는 원인 확인용입니다
4. v0.3.11 이후: SH 최적화 단계를 계수당 스레드 하나로(같은 결과, PC에서 그 단계 시간 약 절반)

## PC(lavapipe) 확인
- 그래디언트: L1만, SSIM만(λ=1), 섞은 손실(λ=0.2) 모두 CPU 유한차분 기준과 일치(SSIM만일 때 상대 오차 약 2e-6), 손실 값 GPU/CPU 일치(1e-6)
- 수렴 테스트: 검증 PSNR 36.83 → **37.14 dB** (D-SSIM 추가 후)
- body 360×640 · 600회, 같은 설정에서 손실만 바꿔 비교: L1만 검증 PSNR 34.96 dB · SSIM 0.9756 → **D-SSIM 포함 36.14 dB · 0.9810** (+1.2 dB). SSIM 단계 시간은 역전파의 약 6%, 전체 학습 시간 약 +7%
- 전체 테스트 통과, Vulkan 검증 레이어 오류 0

## 부탁드리는 것
1. **폰이 식은 상태에서** body **배경 제거 켜고 빠름** → "요약 복사"
2. 가능하면 **고품질**(720×1280)도 → "요약 복사" (시간, 검증 PSNR/SSIM, 발열 헤드룸 줄)
3. 뷰어에서 얼굴·옷 주름 같은 디테일이 전보다 선명한지 봐 주세요 (해상도가 바뀌어서 PSNR 숫자는 이전 버전과 바로 비교하기 어렵습니다)
