# v0.2.0 — M1 스플랫 뷰어

## 변경 사항
- **뷰어 탭** (앱을 열면 바로 보임): Vulkan으로 가우시안 스플랫을 그리는 3D 뷰어
  - 합성 샘플(10만 / 50만 / 100만 개), PLY · SPZ(v2/v3) 파일 열기
  - 한 손가락: 회전 / 두 손가락: 확대·축소와 이동
  - 화면이 바뀔 때만 다시 그림(발열 절약). FPS를 재려면 "연속 렌더링"을 켬
  - 해상도 100% / 75% / 50% 전환
  - 왼쪽 위 HUD: 가우시안 수, 보이는 수, GPU 시간(투영+정렬 / 그리기), FPS, 화면 크기
- **진단 탭** 보완: FP16 측정 방식 수정, 16-bit 키 정렬 추가, int64 atomic · 화면 출력 지원 여부 표시
- 화면 방향을 세로로 고정

## 설치
v0.1.0 위에 **그대로 덮어 설치**하세요 (삭제하지 않아도 됩니다 — 덮어 설치가 되는지도 이번 확인 항목입니다).

## 실제 스캔 샘플 (선택)
Niantic이 공개한 Scaniverse 스캔 샘플입니다 (MIT 라이선스, 약 18 MB, 가우시안 78만 개, SH 3차).
폰 브라우저에서 받은 뒤 뷰어의 "파일 열기"로 선택하세요.

https://github.com/nianticlabs/spz/raw/main/samples/hornedlizard.spz

## 테스트 체크리스트
1. v0.1.0 위에 덮어 설치가 되나요?
2. 앱을 열면 뷰어에 무지개색 매듭(샘플 10만)이 보이나요? 회전 · 확대 · 이동이 자연스러운가요?
3. "연속 렌더링 켬" 상태에서 샘플 10만 / 50만 / 100만 각각의 FPS와 투영+정렬 · 그리기 시간 (HUD 숫자)
4. hornedlizard.spz 열기 → 도마뱀 조각상이 있는 공원이 보이나요? 불러오기 시간, FPS, 회전할 때 깜빡이거나 색이 튀는 곳이 있는지
5. 폰을 접었다 펴도 뷰어가 계속 그려지나요?
6. 해상도 75% / 50%에서 FPS가 얼마나 달라지나요?
7. 진단 탭: **충전기를 빼고 폰이 식은 상태에서** 벤치마크 실행 → "요약 복사"
8. HUD는 스크린샷으로 보내 주시면 가장 좋습니다

## 알려진 문제
- SPZ v4(zstd) 파일과 압축 PLY(SuperSplat 등)는 아직 열 수 없습니다
- 가로 화면은 지원하지 않습니다 (세로 고정)
