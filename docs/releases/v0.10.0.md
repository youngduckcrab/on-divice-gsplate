# v0.10.0 — 완성된 모델의 얼굴 가리기 (모자이크·흐림·선글라스·가면·스마일)

다 만든 3D 모델의 얼굴을 다른 것으로 바꿔서 볼 수 있고, 바꾼 모델을 PLY로 저장할 수 있습니다. 원본 모델 파일은 바뀌지 않습니다.

## 쓰는 법
1. 뷰어 탭에서 모델을 엽니다 (학습 결과의 **[뷰어에서 보기]** 또는 **[파일 열기]**)
2. 아래 줄의 **[얼굴 가리기]** 를 누릅니다
   - 앱이 머리를 여러 방향에서 그려 보고 얼굴을 찾은 다음, 바로 **모자이크**를 씌웁니다 (몇 초)
3. 위쪽 버튼으로 방식을 고릅니다: **원본 · 모자이크 · 흐림 · 선글라스 · 가면 · 스마일**
4. **크기**, **위아래** 슬라이더로 맞춥니다 (손을 떼면 다시 만듭니다)
5. **[PLY로 저장]**: 지금 보이는 모습(가린 모델)을 파일로 저장합니다. 이름은 `원래이름-모자이크.ply` 같은 식입니다

샘플(합성 장면)에는 버튼이 나오지 않습니다. 파일에서 연 모델에만 됩니다.

## 얼굴을 못 찾을 때
- "얼굴을 찾지 못했어요"가 나오면, 화면을 돌려 **얼굴이 정면으로 보이게** 한 뒤 **[이 방향이 얼굴]** 을 누르세요
  - 그 방향 근처에서 다시 찾아 보고, 그래도 못 찾으면 그 방향을 얼굴 쪽으로 정하고 머리 크기로 눈 위치를 짐작합니다
- 위치가 조금 어긋나면 **위아래**, 크기가 안 맞으면 **크기**로 맞추면 됩니다

## 방식별 모습
| 방식 | 모습 | 원래 얼굴 |
|---|---|---|
| 모자이크 | 얼굴을 따라 휘어진 2~3 cm 칸, 칸마다 그 자리 색의 평균 | 없어짐 |
| 흐림 | 얼굴 색을 크게 뭉갠 층, 가장자리는 자연스럽게 섞임 | 없어짐 |
| 선글라스 | 검은 테 + 짙은 렌즈(위가 더 어둡고 반사광), 다리가 귀 쪽으로 감 | 눈만 가려짐, 옆에서 보면 렌즈와 얼굴 사이가 보임 |
| 가면 | 흰 가면, 금색 테두리의 검은 눈구멍, 붉은 입술 | 없어짐 (가면 아래는 맨 피부색) |
| 스마일 | 노란 스마일 원판, 얼굴 앞에 살짝 볼록 | 없어짐 (아래는 맨 피부색) |

## 어떻게 하나 (요약)
- **얼굴 찾기**: 모델에서 머리 위치를 정하고, 머리를 12방향에서 그림으로 그려 ML Kit 얼굴 인식을 돌립니다. 눈 사이가 가장 넓게 보이는 (가장 정면인) 그림들에서 눈과 입을 모델 표면 위의 3D 점으로 올려, 얼굴의 위치·방향·크기(눈 사이 거리)를 정합니다
- **가리개**: 얼굴 표면을 살짝 띄워 감싸는 작은 납작한 가우시안 수천 개로 그립니다. 빛 방향에 따른 명암을 넣어 입체감이 나게 했습니다. 선글라스는 얼굴 앞에 따로 세운 물체입니다
- **원래 얼굴 지우기**: 모자이크·흐림·가면·스마일은 가리개 아래 있던 원래 얼굴 가우시안의 색도 바꾸고, 보는 각도에 따라 달라지는 색 정보까지 지웁니다. 다른 각도에서 보거나 저장한 파일에서 가리개만 지워도 얼굴이 다시 나오지 않습니다
  - 다만 **얼굴의 입체 모양(코·턱 윤곽)은 남습니다**

## PC 확인
- 가상 인물(옆으로 돌린 것 포함)로 만든 시험: 눈 위치 6 mm 이내, 방향 오차 14° 이내로 찾고, 각 방식이 눈을 가리는지, 원래 눈 가우시안에 원래 색이 남지 않는지, 뒤통수는 그대로인지 확인
- 가상 전신 모델 두 개(학습 해상도 270·540)에서 얼굴 인식 → 다섯 방식 모두 정면·옆·위에서 확인. 두 모델의 얼굴 위치 차이 1 cm 이내
- 걸리는 시간(PC CPU 4코어, 머리 근처 가우시안 1.3만 개): 얼굴 찾기용 그림 12장 약 1초 + 얼굴 인식, 방식 바꿀 때마다 0.1~0.15초 + GPU 업로드

## 주의
- 가린 모델을 다른 사람에게 보낼 때도, **원래 모델·데이터셋·촬영 영상에는 얼굴이 그대로 있습니다**. 그것들은 보내지 마세요
- 찍힌 사람의 동의 없이 공유하지 마세요

v0.9.2 위에 덮어 설치하세요.

## 부탁드리는 것
- 직접 찍은 스캔 모델로 [얼굴 가리기]를 눌렀을 때 얼굴을 바로 찾는지, 상태 줄의 문구(그림 몇 장, 눈 사이 몇 mm)를 알려 주세요
- 다섯 방식 중 어색한 것(위치, 크기, 모양)이 있으면 화면을 캡처해 주시면 고치겠습니다
