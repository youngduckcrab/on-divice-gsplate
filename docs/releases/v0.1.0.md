# v0.1.0 — M0 기기 진단

## 변경 사항
- 첫 빌드. 촬영·학습 기능은 아직 없고, 테스트 기기의 능력을 확인하는 **진단 화면**만 있습니다.
- 기기 · GPU(Vulkan) · ARCore 정보 표시
- GPU 벤치마크: 메모리 대역폭, FP32/FP16 연산량, atomic 3종(경합 높음/낮음), 100만 키 정렬(정확성 검증 포함)
- "요약 복사" / "JSON 복사" / "공유" 버튼

## 설치
1. 이 페이지 아래 Assets에서 `gsplat-v0.1.0.apk`를 다운로드합니다.
2. 설치할 때 "출처를 알 수 없는 앱 설치"를 허용합니다.
3. Play 프로텍트 경고가 나오면 "무시하고 설치"를 누릅니다 (자체 서명된 실험용 앱이라 나오는 경고입니다).

## 테스트 체크리스트
1. 앱을 실행하면 "GPU (Vulkan)" 카드에 GPU 이름이 나오나요? (Adreno 750 예상)
2. "ARCore 확인" → 카메라 권한 허용 → 상태와 해상도 목록이 나오나요?
3. "벤치마크 실행" → 끝날 때까지 기다립니다 (수십 초 이내 예상). 화면은 켜진 채로 유지됩니다.
4. 정렬 결과가 "정확"인지, 어디에든 "⚠"나 "실패"가 있는지 확인합니다.
5. "요약 복사" → 대화에 붙여 넣어 주세요.
6. (선택) 폰을 접었다 펴도 화면과 결과가 그대로 유지되나요?

앱이 꺼지거나 멈추면 어느 단계에서 그랬는지 알려 주세요.

## 알려진 문제
- 아직 뷰어(M1)·촬영(M2)·학습(M3) 기능은 없습니다.
