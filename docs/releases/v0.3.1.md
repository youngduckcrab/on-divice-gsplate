# v0.3.1 — 학습 셰이더 수정

v0.3.0에서 Fold6가 학습 시작 시 `vkCreateComputePipelines failed: VK_ERROR_UNKNOWN`으로 실패한 문제를 고친 버전입니다.

## 변경 사항
- **학습 셰이더 수정**: 공유 메모리 배열 크기를 specialization constant 식으로 정하던 부분(Adreno 드라이버가 거부한 것으로 추정)을 고정 크기 + push constant로 바꿈
- **대체 경로 추가**: 그래디언트 합산을 subgroup 연산으로 하는 셰이더를 드라이버가 받아 주지 않으면, subgroup을 쓰지 않는 공유 메모리 버전으로 **자동 전환**합니다 (느리지만 결과는 같음, CI에서 둘 다 수치 검증)
  - 어느 쪽으로 돌았는지는 진행 화면과 "요약 복사"의 **역전파 합산: subgroup / shared** 줄에 나옵니다
- 셰이더를 만들 수 없을 때 **어떤 셰이더가 실패했는지 전부** 오류 메시지에 표시
- zip 불러오기: 파일이 손상됐을 때(CRC 오류) 어느 항목인지와 "다시 받아 주세요" 안내를 표시
- 학습 화면과 요약에 densify로 추가/제거된 가우시안 수 표시

## zip 불러오기 오류 (invalid entry CRC)
GitHub에 올라가 있는 zip 3개를 다시 내려받아 검사했는데 모두 정상이었습니다. **폰에 받은 파일이 다운로드 중에 손상된 것**으로 보입니다. 내 파일(다운로드 폴더)에서 해당 zip을 지우고 다시 받은 뒤 불러와 주세요. lizard zip은 v0.3.0 때 점 구름이 추가되어 어차피 새로 받아야 합니다.

## 설치
v0.3.0 위에 그대로 덮어 설치하세요. 이미 불러온 데이터셋은 그대로 남아 있습니다.

## 테스트 체크리스트
v0.3.0과 같습니다. 특히:
1. head로 **표준** 학습 시작 → 진행 화면이 뜨나요? (실패하면 오류 메시지 전체를 보내 주세요)
2. 진행 화면의 "역전파 subgroup / shared" 표시
3. 끝까지 돌린 뒤 "요약 복사" + 미리보기/뷰어 스크린샷
4. body · lizard zip을 다시 받아서 불러오기가 되는지

지난번 요약에서 **시작 전부터 발열 SEVERE, 배터리 41.5°C**였습니다. 이 상태면 시작하자마자 클럭이 떨어져서 속도를 제대로 잴 수 없습니다. 충전기를 빼고 몇 분 식힌 뒤(배터리 35°C 안팎) 시작해 주세요.
