# v0.6.0 — 녹화하면서 처리: 끝나는 순간 바로 학습

v0.5.0까지는 다 찍은 뒤 사진을 저장하고, 학습할 때 그 파일을 다시 읽었습니다. 이제 **녹화하는 동안 키프레임마다 바로 처리**합니다. [완료]를 누르면 학습할 데이터가 이미 메모리에 준비되어 있습니다.

## 녹화 중에 하는 일 (키프레임마다)
1. 카메라 이미지를 학습 해상도(960×540)로 변환
2. ML Kit 인물 분할
3. **찍는 대상만 남기기**
   - 시작할 때 가운데에서 고른 사람을 기준으로, 그 사람의 몸 중심선에 닿는 영역만 남깁니다
   - 옆에 서 있거나 지나가는 다른 사람은 지웁니다
   - 화면에서 대상과 붙어 보이는 사람은 깊이로 가려냅니다: 대상의 몸 중심에서 0.8 m 넘게 떨어진 부분을 지웁니다(깊이가 있는 프레임만)
4. 학습 데이터에 추가하고, 파일(JPEG·마스크·깊이) 저장은 뒤에서 따로

## 화면에서 대상 강조
- 실시간 인물 분할로 **찍히는 사람은 밝게, 나머지는 어둡게** 보입니다(초당 약 10회)
- 시작 전에는 화면의 모든 사람이 밝게 보이고, [시작] 뒤에는 고른 사람만 밝게 보입니다
- 사람이 화면에서 벗어나면 "사람이 보이지 않아요" 안내가 나옵니다

## 끝난 뒤
- [완료] → 남은 키프레임 1~2장만 마무리 → **[바로 학습]**: 학습 탭으로 넘어가 곧바로 시작합니다
  - 빠름·표준(540)은 파일을 읽지 않고 메모리에서 바로 씁니다. 학습 요약의 불러오기 시간 옆에 "(촬영 직후 메모리에서)"가 나옵니다
  - 고품질(720)이나 같은 스캔을 두 번째 학습할 때는 파일 저장이 끝난 뒤 파일에서 읽습니다
- 파일 저장은 학습과 동시에 진행되고, 끝나면 데이터셋 목록에 `scan-날짜-시간`으로 나타납니다
- 저장 형식이 가벼워졌습니다: 이미지 1280×720(고품질 학습 해상도), 마스크 960×540

## 엔진으로 옮김 (iPhone 대비)
키프레임 선택, 이미지 변환, 대상 고르기, 깊이 판별, 데이터셋 만들기, 파일 쓰기를 모두 C++ 엔진으로 옮겼습니다. 앱 쪽(Kotlin)에는 ARCore(카메라·포즈·깊이 받기)와 ML Kit(인물 분할) 호출, 화면만 남았습니다.

## PC 확인 (가상 촬영을 이 경로로 다시 흘려 봄)
- 학습 화질: 검증 PSNR 36.94 dB (파일로 저장했다가 읽던 방식 37.04 dB, 차이는 JPEG를 한 번 더 거친 영향)
- [완료] 뒤 학습 데이터 준비: 마지막 마스크가 들어오는 즉시(0.1 ms 이하). 파일 저장은 완료 뒤 약 20 ms 안에 끝남
- 키프레임 한 장 처리(PC, 1920×1080 기준): 변환 약 32 ms, 대상 고르기 4~8 ms, 파일 쓰기 약 22 ms(뒤에서). 폰의 인물 분할 시간은 요약에 나옵니다
- 다른 사람이 함께 찍힌 경우(가상으로 한 명 추가):
  - 떨어져 있으면 모든 프레임에서 지워짐
  - 화면에서 대상과 붙어 보이면 깊이 있는 프레임에서 95% 지워짐
  - 깊이 없는 프레임에서는 절반만 지워짐

v0.5.0 위에 덮어 설치하세요.

## 부탁드리는 것 (카메라를 쓸 수 있게 되면)
1. 사람 한 명을 찍으면서 **밝게 강조되는 영역이 사람과 맞는지** 봐 주세요(어긋나거나 늦게 따라오는지)
2. [완료] → **촬영 요약 복사** → 보내 주기. 특히 아래 줄:
   - `처리/장`(사람 분할 ms, 대기 최대 장수)
   - `완료 → 학습 준비`
   - `대상:` 줄
3. **[바로 학습]** → 학습 요약 복사 → 보내 주기(불러오기가 "메모리에서"인지)
4. 가능하면 옆에 다른 사람이 지나가게 해서 그 사람이 어둡게 처리되는지
